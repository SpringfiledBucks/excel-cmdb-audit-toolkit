# 案例名称：Excel / CMDB 多来源数据核对与异常报告

**项目背景：** 该公开版本来源于实际工作中的资产核对与批量数据处理场景，并使用模拟数据重构。多份 Excel/CSV 清单存在字段写法不统一、重复编号和信息不一致，人工逐项核对耗时且容易遗漏。

**本人负责内容：** 将表格读取、字段标准化、多标识符关联、重复检测、差异定位与报告导出整合为可复用的 Python 命令行工具，编写演示数据和测试。

**解决的问题：** 快速定位匹配、冲突、缺失、重复和非法 IP 的记录；每条差异保留来源行号、旧值、新值及原因，方便人工复核。

**技术方案：** Python 3.10+、openpyxl、CSV；按序列号、资产编号、管理 IP、BMC IP 核对，并识别多个标识符指向不同资产的矛盾。输出 Excel、CSV 和 JSON 汇总。

**最终结果：** 公开演示版可在本地用三份模拟表生成核对报告，并通过自动化场景测试。演示数据均为模拟生成，不包含真实生产环境信息；未声称客户部署或业务收益。
